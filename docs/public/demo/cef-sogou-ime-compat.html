预期结果（每个示例独立判定）：
① 示例 A（contenteditable）/ C（canvas + 透明输入层）：CEF + 搜狗下会看到粉色 onCommit(degraded=true)，且 data 恰好是本次提交的文本——无累积、无遗漏。这是推荐路径。
